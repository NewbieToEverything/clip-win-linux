# ClipBridge 桌面验收

每项记录设备、终端、Agent、结果和日志时间。不要在真实对话中按 Enter；使用空白输入区或可撤销测试会话。

| ID | 操作 | 通过条件 |
|---|---|---|
| T01 | 两台 Windows 分别运行 `clipbridge doctor`。 | A、B 返回各自工作空间。 |
| T02 | 启动 ClipBridge，查看连接建立状态；连续上传两次。 | 专用 SSH 子进程持续存在，两次传输复用通道。 |
| T03 | XPipe 关闭或终端未打开时，在 Windows 上传。 | 专用通道仍可连接 Debian，流程不依赖既有 XPipe shell。 |
| T04 | 连续上传图片、普通文件、重复基名文件、嵌套目录、空目录和 Unicode 名称。 | 路径原名与结构正确，SHA-256 和回执一致。 |
| T05 | 上传中切换前台窗口，再切回；上传完成后检查输入框。 | 只在焦点持续稳定且未超时时输入；否则只提示手动取回路径。 |
| T06 | Codex、OpenCode、Hermes CLI 的输入区分别粘贴新图片。 | 记录普通路径文字、真正附件标签、Agent 正确读取图像三个等级；不得把字符输入视为 Paste。 |
| T07 | Pi CLI 用同样图片测试路径和 Agent 文件读取。 | 路径正确；Pi 的工具能读取 Debian 图片。 |
| T08 | 上传大小递增的文件，观察右下角窗口。 | 可见打包、传输字节和校验进度；窗口不抢焦点。 |
| T09 | 复制普通文本后触发；测试中断 SSH、拒绝工作空间和重发同一请求。 | 不上传旧图片、不输入旧回执；同一请求重试不重复写入。 |
| T10 | 用 `stats --all` 记录缓存；设置临时旧文件后运行 `prune --all --dry-run`，再按需清理。 | 统计可见；dry-run 不删除；TTL、配额、近期保护、陈旧暂存和旧缓存行为符合配置。 |
| T11 | 重新启动进程和 Windows 登录。 | 热键注册、SSH 预连接失败和上传失败都有可见提示。 |
| T12 | 设备 A、B 均在异地/非同一局域网访问 Debian。 | 路由和上传仍成功，不依赖同一局域网。 |

## 自动粘贴与剪贴板历史

在目标终端开启 `--auto-paste`，上传一张新图。验证 Codex 是否显示附件标签，再检查 `Win+V` 没有新增对应的路径记录。上传期间复制另一段内容，确认 ClipBridge 跳过自动粘贴并保留新内容。

## 缓存和接收器检查

在 Debian 上检查 `~/.local/bin/clipbridge stats --all`、`systemctl --user status clipbridge-prune.timer` 与服务日志。文件应落在 `~/.local/share/clipbridge/<workspace>/batches/`，清理器每小时运行。验证测试只能使用临时测试 HOME，避免触碰真实上传数据。

## v5.5 原生进度卡片

| ID | 操作 | 通过条件 |
|---|---|---|
| T42 | 在 100%、125%、150%、200% 缩放和异 DPI 双屏上传。 | 中文和数字清晰，卡片完整位于原终端屏幕的工作区内。 |
| T43 | 卡片显示时切换前台窗口、Agent Manager Quick Prompt / Focus。 | 卡片不激活、不吞键；目标变化时不输入路径。 |
| T44 | 连续触发 20 次小文件上传。 | 300 ms 内完成的任务不闪窗；卡片不额外启动 UI 或 PowerShell 进程。 |
| T45 | 上传大文件，观察传输到校验阶段。 | 传输字节标为“已发送”；100% 后仍等 Debian ACK；总量未知时不显示百分比。 |
| T46 | 测重复热键、取消、失败、断线重连和 ACK 丢失。 | 请求事件不会串台；未知提交不显示成功或重复输入路径。 |
| T47 | 上传成功后切换焦点或超时。 | 明确提示“已上传但未自动输入”，跳过写入和粘贴，不按 Enter。 |
| T48 | 测中文、超长名称、控制字符文件名。 | 只显示清洗并截断的名称，不显示源路径或完整错误堆栈。 |
| T49 | 用 MSVC / MinGW 构建并在 Windows 11 亮色、暗色主题检查。 | Direct2D/DirectWrite 链接正确，渲染失败时上传仍可继续并提示。 |
| T50 | 从旧显示适配层切换到原生 TransferEvent 发布器。 | ProgressPresenter 与窗口不用重写；无每次热键启动的 PowerShell/SSH。 |
| T51 | 空闲 30 分钟并反复显示、隐藏、关闭程序。 | 空闲无持续重绘；关闭后无窗口、进程或绘图资源泄漏。 |

T42、T43、T44、T47 和 T51 需要在 Windows 桌面人工查看。SSH 构建和 API 自检不能替代视觉、DPI 或焦点验收。
